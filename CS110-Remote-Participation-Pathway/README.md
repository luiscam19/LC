# CS110 Remote Participation Pathway

This is a simple standalone test website proposing a way to remain active in CS110 when in-person attendance is not possible.

## Files

- `index.html` contains the page structure and written content.
- `styles.css` controls the layout, colors, spacing, and mobile design.
- `script.js` controls the interactive Example Week section.
- `assets/` contains the circuit-board and wiring images used by the design.

## Open the site

Open `index.html` in a web browser. No installation is required.

## Main learning concepts

- Semantic HTML sections and navigation
- CSS layout with Grid and responsive media queries
- JavaScript data, click events, and updating page content
