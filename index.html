REMOTE PARTICIPATION PROPOSAL

A way to stay active in CS110 when I cannot attend in person

This pathway keeps the same assignments and learning outcomes. It replaces the in-person Action Session with documented work, communication, and instructor verification.

Goal: Continue learning and contributing without lowering course expectations.

WEEKLY WORKFLOW

How remote participation would work

  1. Receive the briefingReview Canvas instructions, class notes, examples, and required outcomes.
  2. Plan the missionWrite a short goal and identify the concepts the assignment demonstrates.
  3. Build and documentComplete the work while saving commits, screenshots, notes, and questions.
  4. CommunicatePost progress or questions in the class communication channel and attend a check-in if needed.
  5. Submit evidenceTurn in the finished work, repository link, Action Record, and a short reflection.
  6. Verify learningAnswer instructor questions or demonstrate the project live when requested.

EVIDENCE OF PARTICIPATION

Visible proof of the work

Each week would create a record that the instructor can review.

Git history

Meaningful commits showing when and how the project changed.

Working project

A tested repository link with readable files and a short README.

Action Record

A brief explanation of the goal, process, problems, and result.

Communication

Questions, progress updates, and responses through Canvas, Discord, or email.

Screenshots

Visual checkpoints showing completed stages and testing.

Verification

A short live or recorded explanation when the instructor needs confirmation.
